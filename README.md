# Карточка товара

Локальная программа-прототип **карточки товара**: фото, название, описание.

Сделано в **Victimok Labs**. Позже (когда скажешь) подключим к [Точке Склада](https://github.com/Johny-Silverhand/sklad-uchet): в разделе **Баланс** любую позицию можно будет открыть как такую карточку.

## Что умеет сейчас (v0.1.1)

- список карточек
- создать / сохранить / удалить
- до **4 фото** на карточку, листание стрелками (jpg/png/webp/gif)
- данные только локально, без облака

## Данные

- Windows: `%APPDATA%\VictimokLabs\KartochkaTovara\`
- Linux/macOS: `~/.local/share/VictimokLabs/KartochkaTovara/`
- или путь из `KARTOCHKA_DATA`

Слушает только `127.0.0.1:8765`.

## Запуск

```bash
go run .
```

Сборка:

```bash
go build -o kartochka-tovara .
```

На Windows потом можно обернуть в WebView2-окно по образцу Точки Склада — сейчас для прототипа открывается браузер на localhost.

## Модель (под будущий Баланс)

| Поле | Назначение |
|------|------------|
| `name` | название позиции |
| `description` | описание |
| `photoFile` | локальное фото |
